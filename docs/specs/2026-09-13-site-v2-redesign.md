# onceinyourlife v2 — 전면 개편 설계

2026-09-13 확정. 시안: claude.ai/code/artifact/025d1aae (5개 화면, 사용자 확정).

## 배경과 제약

- 애드센스 **심사 중** (9/2 신청). 제1원칙: **기존 18개 URL은 건드리지 않는다.**
  빈 허브·"준비 중" 페이지는 배포하지 않는다 — 그것이 Low Value Content다.
- 블로그가 28편·6갈래로 성장. 사이트(2갈래)가 따라잡는 확장이 목적.
- 역할: **읽는 곳은 블로그, 계산하는 곳은 사이트.** 같은 브랜드 한 세트.

## 정보 구조 (URL)

```
/                  포털 홈 (v2 전면 재설계)
/silup/…           유지 — 갈래 「일을 그만두게 됐을 때」
/longtermcare/…    유지 — 갈래 「부모님을 돌보게 됐을 때」
/inherit/          [C] 상속 허브 + 가이드 4편
/car/              [D] 자동차 허브 + 가이드 3편
/pension/          [E] 연금·건강 허브 + 가이드 3편
/acquisition/      [F] 취득세 계산기 (지방세법 아카이브, unlazy 별도 게이트)
/gift/             보류 — 홈택스 대조·화면 확인 후 배포
```

홈 카드 6장은 갈래를 "인생 사건" 문장으로 부른다. 미완성 갈래 카드는
블로그로 링크한다(죽은 링크·준비중 페이지 금지).

## 시각 시스템 (시안 확정값)

- 종이 톤: light bg `#f7f5ef` / card `#fffdf8` / ink `#26231c` / sub `#6e6759`
  / line `#e6e1d4` / soft `#efeade`. dark bg `#171511` / card `#211e18`
  / ink `#ece7db` / sub `#a49b8a` / line `#37332a` / soft `#2a2720`.
- 헤드라인 명조: **Gowun Batang** (Google Fonts 400·700) + `'Nanum Myeongjo',
  AppleMyungjo, Batang, serif` 폴백. 본문은 기존 시스템 산세리프 유지.
  ※ "외부 요청 0건" 원칙의 **의도적 예외 1건** — fonts.googleapis.com.
  한글 폰트는 unicode-range 분할 서빙이라 실사용 전송량이 작고,
  self-host(가중치당 ~1.2MB 통짜)보다 이용자에게 낫다.
  개인정보처리방침에 글꼴 로딩 항목을 추가해 정합성을 지킨다.
- 갈래 색 6종 (light / dark):
  silup `#2e62b0`/`#94b9ec` · care `#24785a`/`#8fcfae` · inherit `#7752a8`/`#c4a8e8`
  · home `#a05242`/`#e8a595` · car `#8a6a1c`/`#d6bc6a` · pension `#1d7789`/`#83c7d8`
  대비 게이트(WCAG AA)가 실측 기준이며, 실패 시 게이트에 맞춰 값을 조정하고
  이 문서를 갱신한다.
- 공통 상단 내비게이션 + 전 하위 페이지 브레드크럼 신설.
- 도구 페이지의 자체 `<style>`을 공통 CSS로 흡수한다 — fig.css 사고(클래스
  공백 → 검정 SVG)의 구조적 원인 제거.
- 토큰 아키텍처와 게이트(대비·터치·줄길이·다크·토큰단일소스)는 유지.

## 배포 계획 — 클러스터 단위 원자 배포

| 배포 | 내용 | 상태 |
|---|---|---|
| A | v2 리스킨(기존 18페이지 전부) + 포털 홈 + about 개정 | ← 지금 |
| B | (예비) A에서 미룬 보완 | |
| C | 상속 클러스터 `/inherit/` 허브+4편 | |
| D | 자동차 클러스터 `/car/` 허브+3편 | |
| E | 연금·건강 클러스터 `/pension/` 허브+3편 | |
| F | 취득세 계산기 `/acquisition/` | |
| G | `/gift/` — 사용자 검증(홈택스 대조 6케이스 + 화면 확인) 후 | |

매 배포: 전 게이트 통과 → 커밋 → 푸시 → **라이브 검증**(전 URL 200 ·
canonical · gift 잔재 0). gift/는 커밋하지 않는 상태를 유지하고,
배포 준비 시 트리 밖으로 뺐다가 되돌린다(65551a1 방식).

## 배포 A 범위

1. `assets/tokens.css` v2 값 교체(웜 팔레트·명조 스택·갈래 색 토큰).
2. `assets/site.css` v2 컴포넌트(topbar·breadcrumb·hero·카드·pill·푸터 3단).
3. 전 페이지 공통 topbar·breadcrumb 적용(푸터는 마크업 유지·재스타일). 도구 페이지 CSS 통합은 계산기 리스크가 있어 **배포 B로 이월**.
4. `index.html` 포털 홈: 6갈래 카드(완성 갈래는 내부 링크, 미완성 갈래는
   블로그 링크), 원칙 4항, 신푸터.
5. `/about/` 개정: 블로그와의 관계(같은 운영자·역할 분담) 명시.
6. `/privacy/` 글꼴 로딩 항목 추가.
7. gift/ 도 같은 스킨으로 리스킨(단, 계속 미배포).

## 배포 A가 하지 않는 것

- URL 추가·삭제·이동 없음. sitemap은 18 URL 그대로(lastmod만 갱신).
- 새 글 없음(그건 C~E), 새 계산기 없음(F), gift 배포 없음(G).
