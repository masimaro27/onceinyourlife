# 증여세 계산기 — 설계

작성일 2026-09-02 · 상태: 승인 대기

## 왜 만드는가

블로그가 17편으로 커지면서 사이트가 못 받는 영역이 생겼다.

| 블로그 갈래 | 편수 | 사이트 도구 |
|---|---|---|
| 퇴직·실직 | 5 | `/silup/` ✅ |
| 노후·돌봄 | 5 | `/longtermcare/` ✅ |
| 세금(상속) | 4 | 없음 |
| 증여 | 3 | 없음 |

상속·증여 7편이 유입을 만드는데 받을 그릇이 없다. 증여세부터 만들고 그 구조를
상속세에 재사용한다(상속세는 별도 스펙).

## 적용 범위

**수증자가 거주자이고 기본세율이 적용되는 증여**로 한정한다.
비거주자(증여재산공제 미적용)·특례세율(창업자금·가업승계)·합산배제증여재산은 다루지 않는다.

## 계산 흐름

```
증여재산가액
− 채무인수액                     제47조①  ※ 제47조③ 추정 규정 적용
+ 10년 내 동일인 증여 가산        제47조②  합계 1천만원 이상일 때
= 과세가액
− 증여재산공제                    제53조   관계별·10년 누계 한도
− 혼인·출산 증여재산공제          제53조의2 별개 한도, 합쳐서 1억
= 과세표준                        제55조   50만원 미만이면 부과하지 않음
× 세율 − 누진공제                 제56조 → 제26조
+ 세대생략 할증 30%/40%           제57조①  산출세액 전액 기준(안분 없음)
− 신고세액공제 3%                 제69조②  기준액에 할증 포함, 맨 마지막
= 자진납부할 세액
```

### 독립 검수가 잡아낸 것

초안 설계에서 다음 셋이 틀렸다. 2026-09-02 독립 subagent 유도로 교정했다.

1. **부담부증여 채무를 무조건 차감하게 설계했다.** 제47조③은 배우자간·직계존비속간
   부담부증여에서 채무를 **인수하지 않은 것으로 추정**한다. 객관적 입증이 있어야 차감된다.
   부담부증여는 대부분 부모→자녀이므로 **가장 흔한 경우가 틀렸고, 세금을 실제보다 낮게
   보여주는 방향**이었다.
2. **혼인·출산 증여재산공제(제53조의2)가 통째로 빠졌다.** 국세청 세액계산 흐름도에
   나오지 않아 놓쳤다. 홈택스 간편계산에는 입력란이 있다.
3. **공제 한도를 증여자별로 이해했다.** 제53조는 관계 카테고리별 한도다 —
   아버지·어머니·조부에게 각각 받아도 직계존속 한도는 합쳐서 5천만원이다.

그 밖에 과세최저한 50만원 누락, 세대생략 40% 트리거 기준이 과세표준이 아니라
**증여재산가액**, 신고세액공제는 다른 공제를 뺀 잔액이 기준이라 반드시 마지막이라는 점을 반영했다.

## 입력 — 일상어로 묻는다

기존 두 계산기의 언어 규칙(`이직일 (마지막 근무일)`, `잘 모르면 "일반"을 두세요`)을 따른다.
세무 서식의 용어를 그대로 쓰지 않는다.

| 묻는 말 | 쓰이는 곳 |
|---|---|
| **누구에게서 받았나요** | 배우자 / 부모 / 조부모 / 자녀 / 손자녀 / 형제자매·친척 / 그 밖 |
| **받은 재산이 얼마인가요** | 과세가액의 출발점. 입력값을 한글로 되읽어 준다 |
| **받는 분이 미성년자인가요** | 직계존속 공제액(5천만↔2천만)과 할증률을 가른다 |
| **세대를 건너뛴 증여인가요** | 조부모→손자녀. 아래 참조 |
| **빚도 함께 넘겨받았나요** | 금액 + 입증 여부. 아래 참조 |
| **지난 10년 안에 같은 분께 받은 적이 있나요** | 가산액과 공제 잔여 한도 |
| **결혼이나 출산으로 받은 것인가요** | 제53조의2. 해당 시 금액 입력 |

### 세대생략은 자동 판정하지 않는다

관계를 조부모/손자녀로 쪼개면 자동 판정할 수 있을 것 같지만 **틀린다.**
제57조① 단서가 "증여자의 최근친 직계비속이 **사망**하여 그 사망자의 최근친 직계비속이
증여받은 경우"를 제외하기 때문이다. 조부→손자여도 아버지가 사망했으면 할증이 없다.

국세청 홈택스 간편계산도 이 항목을 **직접 묻는다.** 우리도 묻되 쉽게 묻는다.

### 채무는 금액과 입증 여부를 함께 묻는다

제47조③ 때문이다. 배우자·부모·조부모·자녀·손자녀에게서 받은 경우
**기본값을 「차감하지 않음」으로 두고**, 입증 서류가 있다고 표시할 때만 차감한다.

- 국가·지자체·금융회사 채무 → 해당 기관 확인 서류
- 그 밖의 채무 → 채무부담계약서·채권자확인서·담보설정 및 이자지급 증빙

**양도소득세(증여자)와 취득세(수증자)는 계산하지 않는다.** 다른 세목이고,
배우자·직계존비속 간에는 세 세목이 채무 입증 여부에 따라 함께 뒤집혀
독립 변수로 다루면 모순된 조합이 나온다. 발생 사실만 경고한다.

### 억 단위 입력의 자릿수 사고를 막는다

기존 두 계산기는 만원 단위라 문제가 없었으나 증여세는 억 단위다.
`350000000`에서 0을 하나 빠뜨리면 세금이 10분의 1로 나오는데 본인은 모른다.

**입력값을 한글로 되읽어 준다.** `350,000,000` → `3억 5,000만원`

## 다루지 않는 것

계산기의 편집 원칙(`아카이브에 없는 값은 넣지 않는다`)을 그대로 따른다.

- **재산 평가** — 이미 평가된 가액을 입력받는다. 주식 평가일 기준 등은 계산기가 정할 수 없다
- **양도소득세·취득세** — 부담부증여에서 발생하지만 다른 세목이다
- **납부세액공제·외국납부세액공제** — 과거 증여 산출세액 등 사용자만 아는 값이 필요하다
- **가산세·연부연납·재해손실공제·감정평가수수료** — 감정평가수수료 한도는 원문 미확인
- **비거주자·특례세율·합산배제증여재산**
- 혼인 후 2년 내 미혼인 경우의 사후 정산(제53조의2⑥)

## 검증

### 1층 — 조문 ↔ 산식 (독립 검수로 완료)

2026-09-02 독립 subagent가 원문만 보고 산식을 유도해 위 오류 셋을 잡았다.
구현 후 한 번 더 돌려 구현이 유도 결과와 맞는지 확인한다.

### 2층 — 누진공제표는 스스로 검증된다 ★

누진공제액은 독립 파라미터가 아니라 세율과 구간 경계에서 파생되는 값이다.

```
d_k = d_{k-1} + (r_k − r_{k-1}) × B_{k-1}      d_1 = 0
```

이 점화식이 국세청 표 4개 값(1천만·6천만·1.6억·4.6억)을 전부 재생산한다.
따라서 **세액은 1억·5억·10억·30억 경계에서 연속**이어야 하고, 누진공제액을 하나라도
잘못 넣으면 경계에서 계단이 생긴다. 외부 오라클 없이 오류가 잡히는 자리다.

### 3층 — 경계값 단위 테스트

```
공제 한도 정확히      6억 / 5천만 / 미성년 2천만 / 1천만 / 0
혼인·출산 공제        ①+② 합계 1억 상한, 제53조 누계와 분리되는지
세율 구간 경계        1억 · 5억 · 10억 · 30억 (각 ±1원, 연속성)
과세최저한            499,999 vs 500,000
할증 전환점          미성년 + 증여재산가액 20억 초과 → 30%에서 40%
할증 기준            산출세액 전액 (안분 없음)
10년 합산 문턱        999만 vs 1,000만
신고세액공제 기준액    할증 포함 여부
채무 추정            직계존비속 + 미입증 → 차감 안 됨
비정상 입력          채무 > 재산, 과세표준 음수, 0원
```

### 4층 — 외부 오라클 교차 검증

**국세청 홈택스 「증여세 간편계산」**을 쓴다. 로그인이 필요 없고 입력 범위가
우리 계산기와 거의 일치한다(증여일자·관계·세대생략·미성년·재산가액·혼인공제·출산공제·채무액).

- **자동화는 하지 않는다.** WebSquare라 DOM 조작으로 계산이 걸리지 않고,
  반복 호출은 정부 사이트에 부담이다. **사람이 몇 건 직접 돌려 대조한다.**
- 간편계산에는 **사전증여 입력란이 없다.** 대조할 때는 10년 내 증여를 0으로 맞춘다.

### 5층 — 화면이 엔진과 일치하는가

playwright로 실제 조작해 나온 숫자를 엔진 반환값과 대조한다. 기존 패턴.

### 6층 — 이해 가능성 ⚠ 자동화 불가

게이트로 잡히는 것은 글자 크기·대비·터치 타깃·줄길이뿐이다.
**"이 라벨이 이해되는가"는 사람이 봐야 한다.** 완성 후 화면을 그대로 보여주고
이해되지 않는 칸을 지적받는 것을 검증 단계로 명시한다. 작성자의 자평은 검증이 아니다.

## 배포

**만들되 푸시하지 않는다.** 애드센스 심사 중이므로 로컬에서 게이트까지 통과시키고,
심사 결과가 나온 뒤 배포한다.
