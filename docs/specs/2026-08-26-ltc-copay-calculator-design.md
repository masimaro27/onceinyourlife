# 장기요양 본인부담 계산기 — 1차 설계 스펙

작성 2026-08-26. 브레인스토밍 세션에서 승인된 설계의 문서화.

## 목적

장기요양등급을 받은 가족의 보호자(주 타겟 40~60대)가 재가 서비스 조합 또는 시설 입소를
가정했을 때 **월 급여비용·공단부담·본인부담금**을 추정하는 도구.
네이버 블로그 「살면서 한 번은 겪는 일」의 노후·돌봄 클러스터와 상호 유입 구조를 이룬다.

## 형태와 배포

- 정적 웹페이지. 단일 페이지, 바닐라 JS, 프레임워크·백엔드·빌드 도구 없음
- 파일: `index.html`(UI+스타일) / `data.js`(수가 데이터) / `calc.js`(계산 엔진) / `app.js`(UI 로직)
- `data.js`·`calc.js`는 `window` 전역 + CommonJS 겸용(파일 프로토콜 동작 + node 테스트)
- 배포: 1차 GitHub Pages → 자체 도메인 연결(도메인 구매는 사용자). **배포는 이 스펙 범위 밖**

  인지활동형 방문요양(단가표 없음), 복지용구 품목별 가격, 치매전담형 시설
- 모든 데이터에 기준일과 출처 URL을 주석·화면 양쪽에 명시

## 계산 규칙 (근거: 법 제40조, 시행령 제15조의8, 감경 고시)

- 재가: 월 총 급여비용 = Σ(단가 × 월 횟수). 월 한도액(등급별) 이내분은 부담률 적용,
  **초과분은 전액(100%) 본인부담**
- 시설: 1일당 수가 × 입소일수 × 부담률. 월 한도액 개념 없음
- 부담률: 재가 15% / 시설 20%. 감경 40% → 9%/12%, 감경 60% → 6%/8%,
  의료급여법 제3조제1항제1호 수급자 → 0%(면제)
- 원단위 처리 고시는 아카이브에 없으므로 **반올림 후 "실제 청구액과 원단위 차이 가능" 고지**

## 급여 제한 처리 (아카이브 관찰 범위 안에서)

- 인지지원등급: 단기보호·시설 수가가 고시표에 없음 → 선택 불가 처리 +
  "이용 가능 급여는 장기요양인정서 기재를 따른다" 고지 (명시 금지 문장은 없으므로 단정하지 않음)
- 단기보호 월 9일 초과 입력: 차단하지 않고 경고(연장 예외·가족휴가제 존재를 함께 고지)
- 방문간호: 방문간호지시서 필요 + 발급비 별도 고지
- 동일 시간 중복 금지 규칙은 시간표를 다루지 않으므로 고지문으로만 안내

## 결과 화면

월 총 급여비용 / 한도 대비 게이지(재가) / 공단부담 / **본인부담(강조)** / 초과분 경고.
하단 고정 고지: ①참고용 추정치, 실제 금액은 공단(1577-1000)·이용 기관 확인
